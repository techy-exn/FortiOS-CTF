We've been inside the system settings a few times so you may have noticed that now it is grouped in 4.

- General: system time settings, email service, systerm operating settings...
- Access: administration settings, sso settings, security settings like password threshold...
- Device: start up settings, disk setting...
- Preference: language, workflow management, theming

Predefined and custom themes can then be associated with the FortiOS system, admin profiles or individual administrators.

This means that every administrator can now have their own theme.

Now we have created a custom theme `EXN`. You can change this with the color you want, but why would you do?

Let's head over to `System > Settings > Preferences`

![Go To Preference](/files/830cd62090ada97836455cce8557dcf5/Go_To_Correct_Settings.jpg)

There you can now scroll down and select the custom theme `EXN`
![EXN theme](/files/1fb51207023c0f0aa3d16fffd7efcb5f/Select_Custom_Theme.jpg)

If you then click okay, you will see that the entire FortiGate change's theme.
![EXN theme](/files/8e3accebe593197790b6d6346b7f5399/FG_In_EXN_Theme.jpg)

Now this is a system level change, so every admin will now have this amazing theme.

However from 8.0, you can make override on **admin profile** or even **admin level**.

So let's head over to `System > Administrators` and edit your admin account.
![Going to Admin](/files/6bb736bf0a8ddb878dc9a94a738f1bd0/Going_To_Admin.jpg)

Here you can now select another theme, for example retro.
![Going to Admin](/files/63120a38f2975f9071421bed3e6c8d8e/Override_Theme_Per_Admin.jpg)

![Going to Admin](/files/e769d202d595bda310fd36219b3317f0/Retro_Theme_Activated.jpg)
