**Configuration revisions** are now only available on FortiGates with a disk or FortiGate VM's.

	
You can identify a FortiGate with a disk when the name ends with a 1

Example
* 90G is without disk for logging, 91G is with disk for logging
* 120G is without disk for logging, 121G is with disk for logging

---


The `revision-backup-on-logout` option is now enabled by default. On previous versions it was disabled

It also has been added and you can review it under `system > settings`

![Check Revision Setting GUI](/files/fbb530122f3ac5d7225ab3f522bcf26d/Config_Revision_Setting.jpg)

This setting can also be checked with CLI:

![Check Revision Setting CLI](/files/a35ec47ba06febe36fc6a9b9a3743fca/Config_Revision_CLI.jpg)

These settings are the same and now the configuration will **automatically be saved** when an administrator logs out

Head over to the revisions:

![Going to revisions](/files/e5b8d891d34354e5e0cef04b3437afdf/Go_To_Revisions.jpg)

Here you will see the list of revisions. You will also see that there are already many revisions with the comment **Automatic backup (logout)**. These are the revisions which were automatically created when you log out from the FortiGate.

If you click on one of the revisions you can see that you can revert to this specific revision of delete it.

![Options revisions](/files/731698fb86b044b18cd3399374bb0406/Options_To_Do_With_Rivisions.jpg)

Now change a setting without logging out. For example create another admin account. Afterwards head back over to the `revisions`. At the top you will see that you can save these changes manually.

![After changing](/files/a74864086210fb25c4e95fcef76f4ac0/After_Changing.jpg)

Once you save it, you’ll see that another revision has been added. You’ll also notice that this revision doesn’t contain the **Automatic backup (upgrade)** comment.

This means you don’t need to manually create a revision. Simply logging out with the admin account is enough to create a new revision containing the configured changes.

![After Change Revision Change](/files/2e6acd362be4b952be1ba83368bf23a7/After_Change_Revision_Changed.jpg)
