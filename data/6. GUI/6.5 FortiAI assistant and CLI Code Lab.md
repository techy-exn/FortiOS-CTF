Another new feature is the **CLI Code Lab** assisted by **FortiAI**.

The CLI Code Lab is available from the FortiOS GUI banner and from FortiAI, and it can be used to generate, edit, and execute CLI commands for configuring FortiGate.

When FortiAI uses FortiAI as the AI provider, the following FortiOS documents are used to provide answers: FortiOS Administration Guide, FortiOS CLI Reference. FortiAI also checks its answers against the FortiGate to ensure the results are suitable for the specific model.

Now that we know we have 2,000,000 starter tokens. Let's use them and test out some interesting prompts.

First start by clicking the FortiAI icon on top of the FortiGate webserver:
![select-fortiai.jpg](/files/d8c5d09d6fdd87f8a5a254be602a3db9/select-fortiai.jpg)

The popup gives you the option to use the openAI integration to use your own openAI subscription. For now we will select FortiAI since we have some starter tokens to use. After you select FortiAI click OK and close it

Next openup the CLI Code Lab. Go to the CLI tab on top and click on CLI Code Lab.
![cli-code.jpg](/files/529ebfcf0f3095ef2cdda4786e508c85/cli-code.jpg)

Now for the example we will test a prompt that will check out internet connection towards google.com. So we enter the promp like this:
![test-prompt.jpg](/files/b3d47fe0c0fdbfda1d98d2b307fce60d/test-prompt.jpg)

Press Enter and analyze the output. Check the CLI proposition and execute if you think it is safe and not erase the whole config file :)
![execute-command.jpg](/files/bff34acc18b648a31bf5714cdd19cfe9/execute-command.jpg)

Analyze and watch the output of the execute command:
![analyze-output.jpg](/files/4ee2fc24368ccfc2e81cc464d893d571/analyze-output.jpg)

That worked great. Now feel free to play around with it and yes you may consume all your starter tokens. Happy prompting!!!
