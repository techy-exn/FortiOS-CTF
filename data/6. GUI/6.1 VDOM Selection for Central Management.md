<p>

FortiOS 8.0 adds GUI support for selecting which VDOM is used for FortiManager communication, a setting previously only configurable via CLI

First enable Virtual Domains
	
	
<div class="info">

A VDOM (Virtual Domain) splits one physical FortiGate into multiple independent virtual firewalls, each with its own interfaces, policies, routing, and security settings.

</div>

Head over to `System > Settings > General`

![Check Revision Setting GUI](/files/4655ba195deeca9791225dcbbf7d5a09/Go_To_Settings.jpg)

Here you can now enable Virtual Domains:
![Enable VDOM](/files/78915e0969bd3dc03b9f30229d46a4a1/Enable_VDOM.jpg)

You will get a warning message which you need to accept.
![Warning message](/files/b30456244913af9b0af2dd6d1be9d3e8/Confirm_vdom.jpg)

After this you will be logged out from the firewall. Log back in with your account and you will now see that VDOM's are enabled:
![VDOMs enabled](/files/9111303d615ebb9c69b0b4db07a85799/VDOM_enabled.jpg)

Head over to `Security Farbic > Fabric Connectors > Central Management`

![VDOMs enabled](/files/9864a43b605731e934d6c705e250143d/Go_To_Central_Management.jpg)

If you **double-click** on central management you will see that you can now decide which vdom has communication with the FortiManager.

![VDOMs enabled](/files/788096005e08c5505965e5bac8cb5bd8/Central_Management_Settings.jpg)

Before you had to do this with the CLI:

```
config system central-management
    set type fortimanager
    set fmg "10.10.10.100"
    set vdom "root"
end
```
