The options in the **Dashboard** tree menu have been consolidated to the following default sub-menus:

- **Status**
- **Asset and Identities**
- **Network Monitor**
- **FortiView**
- **WiFi**

Sub-menus now use tabs to organize information. Some sub-menus, such as Status and WiFi, display one tab of widgets by default. Other sub-menus, such as Assets and Identities, Network Monitor, and FortiView display multiple tabs of information by default. Administrators can customize dashboards by adding widgets or tabs to existing dashboards or by adding new dashboards.

The dashboard template has been removed. Resetting the dashboard now returns it to the default sub-menus.

In the GUI, expand Dashboard to view the new sub-menus. In the following example, the Status dashboard is selected and displays a number of widgets.

---	
	
## Add widget to dashboards without tabs
On a dashboard without tabs, such as Status or WiFi, click Add widget. The Add dashboard widget pane is displayed.

The available widgets are organized under tabs, such as FortiView in the following example:

![widget-without-tab.jpg](/files/e97f0e8125bdfd0281662b5eb006dfad/widget-without-tab.jpg)
	
![dash-widget.jpg](/files/004a9d1f12690378f46581a86b254134/dash-widget.jpg)
	
Then click any widget you want to add.
