## Step 1 – Verify the SD-WAN Members

Navigate to:

**CLI icon top right → CLI Console**

Confirm that:

- Both interfaces are operational.
- The estimated bandwidth values are displayed.

```
show system interface port8
```

&

```
show system interface port 9
```

<br>

## Step 2 – Review the Performance SLA

Open the configured **Performance SLA**.

Verify that:

- Both WAN members participate in the SLA.
- Both members are healthy.

Open the **CLI Console** again and enter these commands:

```
config sys sdwan
```

```
config members
show
```

![members-command.jpg](/files/4388d1c84b0e0c71a039dad0fd5f2eb3/members-command.jpg)

<br>

Now go back by entering `end` and executing following commands:

```
config service
show
```


![rule-information.jpg](/files/5420bdea3b651c1b85ebc393ab7d0beb/rule-information.jpg)


Here you see the rule created for the bandwith steering note that this only possible if the load-balance option is enabled and the hash-mode is defined. At this moment this is only configurable via **CLI**.
