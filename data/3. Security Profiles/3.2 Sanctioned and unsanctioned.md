Now we want to block the upload of files to Claude. There are 2 ways we can do it. We can have a filter override on this specific application on put it on block.
	
However if there are more you want to block, you can also choose to unsanction this app. And afterwards you can decide what you want to do with all the unsanctioned apps.
	
Go back to your **Application Control Profile** and click open the application control of GenAI:

![Open GenAI](/files/fa2f9103faefb9f08b9923f9b2a1fe35/Edit_Gen_AI.jpg)

Find the correct signature (**Claude_File.upload**):
![Finding signature](/files/74955388cde7530bd74c4dc10b3eae15/Find_Claude_Upload.jpg)

Now we can classify it as unsanctioned:
![Finding signature](/files/1c0b076f82b141c1b7b5935b208187ef/Claude_Unsancioned_.jpg)

Inside the Application control profile, make a filter override and put all the unsanctioned apps on block.
	
![Override unsanctioned](/files/a616bdbc076a4e2e3629da561691350c/image_7.png)

![Override unsanctioned](/files/d99518fdf35fcc61dd6d379596ff8ecf/Block_Override_Unsanctioned.jpg)

Once added, you will see that the filter override has been added to the profile

![Override unsanctioned](/files/0fbd90772b918b3f76ea342ba946fd12/image_5.png)

Now we have to make sure that we also change the firewall policy. If you want to block file uploads to claude, you will require deep inspection. 
	
![Policy to block](/files/786f97bd514361f9669e5b7537b9e4c8/image_4.png)

![Override unsanctioned](/files/b4d73e2dd0ffabb3cc5fbc4d2a0efdc1/image_6.png)

</div>

Now it's time to test, you can open claude desktop and you can try to upload a file.

![Upload Claude](/files/b45941b16f758336ef31234168c4036f/Upload_Claude.jpg)

You will immediatly see that the upload has been blocked

![Upload blocked](/files/1bd81368fe6604180353bc1bb1427a8f/Upload_Blocked.jpg)

Time to check the logs. Head back to log and report and check the application control logs. Put a Filter on Claude_File.Upload and you will see that your action has been blocked

![Override unsanctioned](/files/c0d9cdc20f208a37efe9523b15735481/Upload_Blocked_Logs.jpg)
