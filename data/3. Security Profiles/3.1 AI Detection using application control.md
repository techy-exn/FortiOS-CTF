In **FortiOS 8.0**, Application Control introduces new classifications to provide better visibility and control over the use of **Generative AI applications**.

---

Before moving on, let's understand what these classifications mean.

⚪ **Unclassified** — `UNKNOWN`
The application has **not yet been classified** as sanctioned or unsanctioned.  
*No organizational decision has been made yet.*


🔴 **Unsanctioned** — `NOT APPROVED`
The application is **not approved for use** within the organization.  
*This does not mean the application is malicious — it simply does not align with organizational policy.*

> **Example:** Dropbox could be unsanctioned when the organization has standardized on OneDrive.


🟢 **Sanctioned** — `APPROVED`
The application is **approved for use** within the organization.  
*The organization has explicitly accepted its use.*

> **Example:** Microsoft Copilot could be sanctioned when it is the organization's approved Generative AI platform.

We will be creating an application control profile. Application control can now be used to detect agentic AI protocols, such as Model Context Protocol (**MCP**) and Agent-to-Agent Protocol (**A2A**). 

New AI-specific log fields and FortiView enhancements provide deeper insights into AI-driven activity, improving oversight and security for emerging AI workloads.



## Step-1: Create Application control security profile

Navigate to: `Security Profiles > Application Control`

1. Click Create New.

2. Enter the name: **Monitor AI**

3. Set the generative AI category to Monitor. 

4. Configure other fields, as needed. Make sure you set the inspection profile to certificate inspection.

5.Click OK.

![Creating profile](/files/7cdd00700674804b756ee563f0a95b8c/Create_Profile.jpg)

<div class="info">

Dependent on which AI application you want to monitor, you need to put your inspection profile to either deep-inspection or certificate-inspection.
You can find this if you hover over the application signature.
	
![Fortigate.jpg](/files/c7602b32233f7c292f9580b30de7bd04/Requirement_Deep_Inspection.jpg)
 
For the AIAP database to be updated, ensure that at least one firewall policy is utilizing an application control profile. If you are using FortiManager as license server, make sure you upload the database inside your FortiManager first.

</div>
