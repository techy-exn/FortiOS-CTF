# Your Virtual Lab Environment

Each participant receives an isolated CloudShare environment containing everything required for the workshop.

Your environment includes:

* **Windows Workstation** – Your primary client for accessing the FortiGate GUI and other web-based tools.
* **Additional lab resources** – Depending on the exercise, supporting systems may be available to demonstrate specific FortiOS 8.0 features.

<br>

All systems are accessible through **CloudShare**, allowing you to connect using only a web browser. Since you're reading this guide, you've already successfully logged in.

Within CloudShare, several tools are available to make working in the lab as smooth as possible.

<br>

## Machine Access

Available connection methods are shown on the left after selecting a machine.

![VM list](/files/28bc4590e2f973f8341c3c4648a92bf6/Overview_machines.jpg)


For the **Windows Workstation**, use **CON**. Log in using your assigned workshop credentials.

<br>

Within Cloudshare whenever you want to do something with a machine you can use the `actions`

![All actions](/files/21df734267e53f16c219ec54991802b7/All_actions.jpg)

* **Send Username** – Automatically enter the configured username.

* **Send Password** – Automatically enter the configured password.

* **Send Ctrl-Alt-Del** – Useful when logging into Windows.

![Cloudshare Send Ctrl Alt Del](/files/00699854d89c60134d308f234271371f/Cloudshare_SentCtrlAltDel.jpg)

* **Full Screen** – Expand the virtual machine for a larger workspace.

![Full Screen](/files/557c9ed5e29f0f056d6753b7ef99802a/Operations_FullScreen.jpg)

# Keyboard Layout

<br>

The workshop machines use a **QWERTY** keyboard layout by default.

If you're using an **AZERTY** keyboard, you can switch the Windows keyboard layout using the standard Windows shortcut:

You can easily change the keyboard layout within the Windows virtual machine. Both QWERTY and AZERTY layouts are already installed, so you can switch between them whenever needed.

![Change keyboard layout](/files/f2e326d157074d7d6a0de31ee3b34ebf/Change_Keyboard_Windows_10.jpg)

**Do not use the option of cloudshare to change the keyboard. Change it inside the machine.**
