## Step-1: Configure a ZTNA port

From the FortiGate, go to `ZTNA > Ports` and create a new IPv4 port.

1. Click `Create New`.
2. Enter a name for the ZTNA port.
3. Select the interface that will receive the client connections.
4. Enter an IP address for the access proxy VIP.
5. Enter the external port to listen on.
6. Select the default certificate clients will see when connecting.
7. Click `OK`.

> The IP address and port must not conflict with interface management access. If required, use another address on the same subnet.


This creates the ZTNA application gateway, which is the endpoint remote users connect to over HTTPS.

---

## Step-2: Configure a ZTNA server

Map the ZTNA port to the real servers that clients will connect to.

A ZTNA server can be either a Web server or a traffic forwarding server. In the following example, we will create a ZTNA web server.

To create a ZTNA web server for using the basic method in the GUI:

1. Go to Policy & Objects > ZTNA > Servers & Portals.
2. Go to Web Server sub-menu and click Create New.
