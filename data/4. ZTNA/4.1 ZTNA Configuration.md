## Step-1: Configure a ZTNA port

From the FortiGate, go to `ZTNA > Ports` and create a new IPv4 port.

1. Click `Create New`.
2. Enter a name `ztna-app` for the ZTNA port.
3. Select the interface that will receive the client connections `IT (port3)`.
4. Enter an IP address for the access proxy VIP `10.10.10.100`.
5. Enter the external port to listen on `9443`.
6. Select the default certificate clients will see when connecting `Fortinet Factory`.
7. Click `OK`.

> The IP address and port must not conflict with interface management access. If required, use another address on the same subnet.

![alt text](/images/ZTNA1.jpg)
![alt text](/images/ZTNA-2.jpg)

This creates the ZTNA application gateway, which is the endpoint remote users connect to over HTTPS.

## Step-2: Configure a ZTNA Web server

Map the ZTNA port to the real servers that clients will connect to.

A ZTNA server can be either a Web server or a traffic forwarding server. In the following example, we will create a ZTNA web server.

To create a ZTNA web server for using the basic method in the GUI:

1. Go to Policy & Objects > ZTNA > Servers & Portals.
2. Go to Web Server sub-menu and click `Create New`.
3. Enter a name `ztna-dashboard-app` for the ZTNA Web Sever.
4. Host will be this FQDN `ztna.dashboard.local` make sure it resolves to 10.10.10.100.
5. Define the ZTNA port you just created `ztna-app`.
6. Internal Server IP needs to be on `Specify` because we use a custom `HTTP` port `8880` on IP `172.16.1.2`.
7. Finally click on `OK`.

## Step-3: Configure a ZTNA Firewall policy

For the final step of the configuration we need to create a ZTNA firewall policy to let the traffic flow to our web-server with keeping ZTNA in check.

To create a ZTNA firewall policy use this method in the GUI:

1. Go to Policy & Objects > Firewall Policy.
2. Click `Create new`.
3. Enter a name: `ztna-app-access` > Type: `ZTNA` > Incoming interface: `IT` > Source: `all` **or** specify only the `PC` > Security posture tag: `paint-running` > ZTNA port: `ztna-app` then leave the rest on default settings.
4. Finally click `OK`.

![alt text](/images/ZTNA-Policy.jpg)

Make sure after you click create the policy is **above** all other policy's!
